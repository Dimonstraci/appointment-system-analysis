# Размещение на GitHub

Рекомендуемое имя репозитория: `appointment-system-analysis`.

Описание: `Учебный кейс Junior системного аналитика: требования, BPMN/UML, ERD, OpenAPI и приёмка системы записи на услуги.`

Темы: `system-analysis`, `portfolio`, `requirements`, `bpmn`, `uml`, `openapi`.

## Через Git

1. В своём GitHub создайте пустой репозиторий с указанным именем. Для портфолио выберите Public. Не добавляйте автоматически README или лицензию: README уже есть в проекте.
2. Откройте терминал в папке проекта.
3. Если папка ещё не является Git-репозиторием, выполните `git init -b main`.
4. Настройте имя автора и адрес коммитов (можно использовать GitHub noreply).
5. Выполните команды ниже, заменив YOUR_USERNAME своим GitHub username, а не email.

```powershell
git add .
git commit -m "Add system analyst portfolio case"
git remote add origin https://github.com/YOUR_USERNAME/appointment-system-analysis.git
git push -u origin main
```

Если коммит или origin уже существуют, соответствующий шаг пропустите. Пароль аккаунта не вставляйте в URL или команду: используйте штатный вход Git Credential Manager.

## Через браузер

Создайте репозиторий, выберите загрузку существующих файлов и перетащите **содержимое** папки проекта с сохранением вложенных каталогов. README должен оказаться в корне. Не загружайте архив вместо распакованных файлов и не добавляйте `.git`.

После публикации откройте README и ссылки на документы; проверьте отображение Mermaid. Спецификацию JSON можно скачать и импортировать в редактор OpenAPI. До публикации URL репозитория в документах намеренно не указан.
