# 07. Приёмка и трассировка

Ниже — спецификация тестов для будущей реализации. Статус всех TC: **не выполнен**, поскольку сервера и тестовой БД нет. Не путать с проверкой файлов репозитория.

## Фикстуры

Контролируемое серверное время `2026-09-10T08:00:00+04:00`. Клиенты A и B, администратор O. Активная услуга S длительностью 60 минут, специалист P. Независимые слоты: X 10:00–11:00, Y 11:00–12:00, Z на следующий день. Перед каждым тестом состояние восстанавливается. Для конкуренции использовать новый свободный слот. Часы подменяются на тестовом стенде, а не на рабочей системе.

## Сценарии Given / When / Then

| ID | Given | When | Then |
|---|---|---|---|
| TC-01 | Активная S и неактивная T | GET /services | 200, только S |
| TC-02 | X свободен, Y занят, Z другой даты | Поиск S на 10 сентября | 200, только X; специалист и offset присутствуют |
| TC-03 | X свободен, токен A | Создать запись с новым ключом | 201; clientId=A; одна CONFIRMED в БД |
| TC-04 | X свободен | 50 клиентов одновременно создают запись с разными ключами | Один 201, остальные 409; одна активная запись |
| TC-05 | Успешный POST A; ответ потерян | Повтор с тем же ключом и slotId в течение 24 ч | Исходный 201, то же тело и ID; одна строка записи |
| TC-06 | Ключ A использован для X | Повтор ключа для Y до TTL | 409 IDEMPOTENCY_KEY_REUSED; Y не занят |
| TC-07 | Запись принадлежит A | B читает или отменяет её | 404, состояние не изменилось |
| TC-08 | X начинается ровно через 2 часа | A отменяет с причиной | 200 CANCELLED; X появляется в доступных |
| TC-09 | До X осталось 1 ч 59 мин 59 с | A отменяет | 409 CANCELLATION_WINDOW_CLOSED; CONFIRMED |
| TC-10 | До X осталось 30 мин | O отменяет с причиной | 200; cancelledBy=O |
| TC-11 | X начинается ровно сейчас | O отменяет активную запись | 409; запись не меняется |
| TC-12 | Запись уже CANCELLED, слот в прошлом | Владелец повторяет отмену с другой непустой причиной | 200; исходные cancelledAt/By/Reason сохранены |
| TC-13 | A отменил X | B создаёт запись на X до начала | 201, новый ID; история A сохранена |
| TC-14 | Нет токена / истёк токен | Создание или чтение записи | 401; нет изменений |
| TC-15 | Токен client | GET /admin/appointments | 403 |
| TC-16 | Невалидная дата / UUID / отсутствует ключ / пустая причина | Соответствующий запрос | 422; нет изменений |
| TC-17 | Невалидный JSON | POST с корректным токеном | 400 INVALID_JSON |
| TC-18 | В БД нет нужного слота | Создание | 404 NOT_FOUND |
| TC-19 | Сегодня 10 сентября | Поиск на 9 сентября / 10 октября | 422 (вне 30 дат); 9 октября допустимо |
| TC-20 | Слот уже начался / услуга неактивна | Создание по известному ID | 409 SLOT_UNAVAILABLE |
| TC-21 | Сбой до commit | Повторить запрос с тем же ключом | Нет частичной записи; после восстановления один 201 |
| TC-22 | День содержит CONFIRMED и CANCELLED | O получает список | Все записи дня, сортировка по startsAt, id |
| TC-23 | Локально 00:30, по UTC предыдущая дата | Поиск по локальной дате студии | Слот попадает в верный день |
| TC-24 | Два соседних слота одного специалиста | Импорт [10,11) и [11,12) | Разрешено; пересечение [10:30,11:30) отклонено |
| TC-25 | Запись отменена после успешного POST | Повтор исходного POST до TTL | Исходный 201 CONFIRMED; GET показывает CANCELLED |
| TC-26 | Результат ключа старше 24 часов, X отменён и ещё доступен | Новый POST с прежним ключом | Может создать новую запись; клиент предупреждён о TTL контрактом |

## Условия передачи в разработку

Перед передачей необходимо согласовать допущения A-01–A-06, решить или явно отложить открытые вопросы и провести ревью сценариев TC-04, TC-08–09, TC-21 и TC-25 с разработчиком и QA. Для релиза дополнительно нужны реализация, исполнение приёмки, проверка безопасности и измерение NFR.
